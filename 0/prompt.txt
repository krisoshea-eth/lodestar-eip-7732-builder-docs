Cycles
In Team settings → Cycles:
Duration: 1 week
Start day: Monday
Cooldown: 0 weeks
Upcoming cycles: 15
Leave automatic addition of active issues off initially
Manually add only ready or active Core work
Keep Backlog, Conditional and Deferred issues out of cycles
Linear supports one-week cycles, configurable start days and zero cooldown. [Linear cycle settings](https://linear.app/docs/use-cycles)

Git automation
Use these guarded settings:
Copying an issue branch name: move to In Progress
PR becomes ready for review: move to In Review
PR merged: no automatic move to Done
Move to Done manually only after the issue’s tests, evidence and documentation are complete
Include LOD-xx in every implementation branch and PR
Do not enable automatic draft-PR conversion. Linear supports branch and PR-driven workflow automation. [GitHub integration](https://linear.app/docs/github-integration)
