# Lodestar EIP-7732 Builder Docs

This repository mirrors the Lodestar EIP-7732 Builder project documents as raw Markdown so the Lodestar team can review and comment through GitHub pull requests.

The human-facing HackMD notes remain useful for writing and publishing. This repo gives the same material a GitHub review surface. The full implementation plan exceeds HackMD's per-note character limit, so GitHub is canonical and its HackMD note is a short landing page.

## Syncing With HackMD

See [HACKMD_SYNC_GUIDE.md](HACKMD_SYNC_GUIDE.md) for the exact HackMD GitHub Sync setup.

The short version:

1. Install the HackMD GitHub App for this repo only.
2. Open each HackMD note.
3. Use **Versions and GitHub Sync**.
4. Link the note to the matching Markdown file in this repository.
5. Push HackMD changes to GitHub or pull GitHub changes back into HackMD deliberately.

HackMD GitHub Sync is manual push/pull, not live automatic bidirectional sync.
