## Findings and disposition

### SlotBidder post-policy coverability

Fork #77 computes available balance after reserve and unsettled liabilities, but trusts the injected policy's returned value. Bid assembly rejects malformed numeric values without checking that the bid fits this available balance. A policy returning 101 Gwei against 100 Gwei available caused one retention and one publication in the reproduction.

Fixed at `75037946b79e`: reject values greater than the calculated coverable amount after pure assembly validates the numeric domain and before storage, signing or publication. Six Gloas/Heze regressions cover exact coverability, one above it, reserve/unsettled deductions and a valid retry after rejection. This is a SlotBidder boundary check, not a request to expand the deliberately arithmetic-only policy contribution #10. LOD-73 records the finding.

### Event codec candidates

In #9854, the block import path omits blockHash/builderIndex on self-builds while the Gloas serializer requires both. An actual codec regression fails for that event shape. Required post-Gloas fields including the self-build index would be consistent with the existing discussion, but this does not select the final event proposal.

In #9875, the full-bid event is fixed to the Gloas SSZ type. A Heze bid serialized through that selected type loses inclusionListBits. This matters if the full-bid candidate is retained; it is not a reason to require full bids or bid_root in the lightweight event proposal.

### Environment script

Marko's #10010 skips derivation and key copies when derived/ exists. A partially completed first run can therefore leave missing keystore/password files on a successful rerun. A mocked execution of the actual script reproduced exit 0 with neither final file present.

The same script only builds the local BN image when its tag is absent. A rerun after source changes silently reuses the older image. Rebuild by default or make reuse explicit and document it.

Builder-docs #27 adds a second, older sidecar script. Prefer one maintained implementation and keep the two-BN configuration's purpose explicit. ENV-03 development convenience is not ENV-02 independent reproduction.
